# Manish Kumar - Profile Page

Research-focused personal website for Manish Kumar, covering tabular deep
learning, numerical feature representations, splines, agentic AI, publications,
and open-source projects.

## Development

```bash
npm install
npm run dev
```

## Static build

```bash
npm run build
```

The deployable static website is generated in `out/`.

## Deployment

Every push to `main` builds and deploys the site through GitHub Pages.
